# Translatorlight

Маленький виджет-переводчик для Windows 11. Он висит поверх остальных окон и ждёт,
пока на него перетащат текст. Выделили английскую фразу в браузере, в PDF или в
переписке, потянули мышью на виджет — и в нём же появляется русский перевод,
уже выделенный и уже скопированный в буфер. Остаётся нажать Ctrl+V там, где он нужен.

Если текста под рукой нет, щёлкните по виджету и просто напечатайте фразу в верхнем
поле: Enter переведёт её, Shift+Enter перенесёт строку.

![Как выглядит виджет](docs/preview.png)

Значок в области уведомлений прячет и показывает окошко, а само окошко можно
таскать за шапку в любой угол экрана — оно запомнит, где вы его оставили.

> [!NOTE]
> Это первая версия: код собран и проверен сборкой, но на живой Windows ещё не
> обкатан. Если что-то ведёт себя не так, это, скорее всего, ошибка, а не задумка.

## Как этим пользоваться

| Действие | Что происходит |
| --- | --- |
| Перетащить выделенный текст на виджет | Перевод появляется в окошке — выделенный и в буфере обмена |
| Щёлкнуть по окошку и напечатать текст | Курсор встаёт в верхнее поле; Enter переводит, Shift+Enter переносит строку |
| Ctrl+V в верхнем поле, затем Enter | Переводит то, что было в буфере обмена |
| Потянуть «⇗ перетащить» мышью | Перетаскивает готовый перевод в любое другое окно |
| Левая кнопка по значку в трее | Показать или спрятать окошко |
| Правая кнопка по значку | Меню: направление, сервис, настройки, выход |
| Esc | Стирает набранное, а если поле пустое — прячет виджет |
| F5 | Перевести тот же текст заново |

Верхнее поле — обычное поле ввода: в него можно печатать, вставлять и править
текст, а перетащенный фрагмент попадает туда же, поэтому его легко поправить и
перевести ещё раз. Курсор встаёт в него от щелчка по любому пустому месту виджета,
так что целиться в само поле не нужно.

Перетаскивать можно не только выделенный текст: виджет принимает фрагмент
веб-страницы вместе с разметкой (её он вычистит) и текстовый файл, брошенный из
проводника — `.txt`, `.md`, `.srt`, `.csv` и подобные.

> [!IMPORTANT]
> Windows 11 по умолчанию прячет новые значки в «карман» — стрелочку слева от
> часов. Чтобы значок всегда был под рукой, вытащите его на панель задач:
> **Параметры → Персонализация → Панель задач → Другие значки в области
> уведомлений → Translatorlight → Вкл.** Либо просто перетащите значок из
> «кармана» на панель задач мышью.

## Почему перевод сразу выделен

Затем, что почти всегда его нужно куда-то вставить. Поэтому виджет делает три
вещи разом: показывает перевод, выделяет его целиком и кладёт в буфер обмена.
Выделение видно даже тогда, когда активно другое окно, — так видно, что перевод
готов целиком, а не наполовину. Если копировать в буфер не нужно, отключите
**«Сразу копировать перевод»** в меню: выделение останется, и перевод можно будет
взять привычным Ctrl+C.

Виджет никогда не забирает себе фокус ввода — ни при запуске, ни когда на него
что-то бросают. Вы перетащили текст, не отрываясь от своего окна, и в нём же
нажали Ctrl+V.

## С какого языка на какой

По умолчанию направление выбирается по самому тексту: латиница переводится на
русский, кириллица — на английский. Это удобно, когда изредка нужно и обратно.
В меню направление можно закрепить: **Всегда EN → RU** или **Всегда RU → EN**.
Текущее направление написано в шапке окна, и там же его можно переключать
кнопкой со стрелками.

## Чем переводит

Тремя бесплатными сервисами подряд: **Google**, **MyMemory**, **Lingva**. Ключи и
регистрация не нужны, нужен только интернет. Если первый сервис молчит, отвечает
ошибкой или исчерпал дневной лимит, виджет молча берёт следующий — пауза выходит
в секунду, а не в отказ. В меню можно поставить первым любой из них; остальные
останутся подстраховкой.

Длинный текст режется на куски по границам абзацев и предложений, переводится по
частям и снова собирается вместе, поэтому абзацы не слипаются. За один раз виджет
берёт не больше 5000 знаков — он для фраз и абзацев, а не для книг.

## Настройки

Всё настраивается из меню по правой кнопке по значку:

- **Направление** — авто, всегда EN → RU или всегда RU → EN.
- **Сервис перевода** — какой из трёх пробовать первым.
- **Поверх всех окон** — чтобы на виджет всегда было куда бросить текст.
  По умолчанию включено.
- **Сразу копировать перевод** — класть перевод в буфер обмена. По умолчанию включено.
- **Приглушать, пока не активен** — окошко становится чуть прозрачным, когда вы
  работаете в другом окне, и снова плотным, когда на него тянут текст.
- **Запускаться свёрнутым** — при старте показывать только значок в трее.
- **Запускать вместе с Windows** — запись в ветку реестра `Run`.

Настройки и положение окна хранятся в `%APPDATA%\Translatorlight\settings.json`
и переживают перезапуск. Испорченный файл не мешает запуску — программа просто
вернётся к значениям по умолчанию.

## Установка

Готовый `Translatorlight.exe` собирается в GitHub Actions: откройте вкладку
**Actions**, выберите последнюю сборку и скачайте артефакт `Translatorlight-win-x64`.
Это самодостаточный файл — .NET ставить не нужно, программа не требует установки
и прав администратора. Положите его в любую папку и запустите.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
dotnet publish src\Translatorlight\Translatorlight.csproj -c Release -r win-x64 `
  --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true `
  -o publish
```

Готовый файл окажется в `publish\Translatorlight.exe`.

Проект собирается и с Linux или macOS (в csproj включён `EnableWindowsTargeting`),
что и делает workflow в `.github/workflows/build.yml`.

## Как устроено

| Файл | Зачем |
| --- | --- |
| `src/Translatorlight/Program.cs` | Точка входа, защита от второго запуска |
| `src/Translatorlight/WidgetForm.cs` | Само окошко: поле ввода, приём перетаскивания, показ перевода, перенос окна |
| `src/Translatorlight/TrayApplicationContext.cs` | Значок в трее, меню, состояние значка |
| `src/Translatorlight/Translator.cs` | Выбор направления, нарезка текста, перебор сервисов |
| `src/Translatorlight/TranslationProviders.cs` | Google, MyMemory, Lingva и общий HTTP-клиент |
| `src/Translatorlight/DroppedText.cs` | Достаёт текст из перетащенного: текст, HTML, файл |
| `src/Translatorlight/TrayIconRenderer.cs` | Рисование значка в трее |
| `src/Translatorlight/AppSettings.cs` | Чтение и запись `settings.json` |
| `src/Translatorlight/Autostart.cs` | Запись в ветку реестра `Run` |
| `tools/generate_icon.py` | Генерация `translatorlight.ico` — значка самого exe |
| `tools/generate_preview.py` | Генерация `docs/preview.png` для этого README |

Окно без рамки: заголовок и рамку Windows рисовать нечему, поэтому шапка сделана
обычной панелью, а перенос окна отдан самой Windows — при нажатии на шапку окну
посылается то же сообщение, которое оно получает при перетаскивании за настоящий
заголовок. Ручное перетаскивание по координатам мыши заметно отстаёт от курсора,
а это — нет. Углы скругляет сама Windows 11; на Windows 10 окно просто останется
прямоугольным.

Приёмником перетаскивания объявлено каждое поле виджета, а не только окно
целиком: иначе текст, брошенный на поле перевода, не дошёл бы до обработчика.
Побочный эффект — когда курсор идёт по окну от поля к полю, Windows успевает
сообщить «перетаскивание ушло», и подсветка мигала бы; поэтому она гаснет не
сразу, а спустя долю секунды, если новое «пришло» так и не случилось.

Цвета окна и значка берутся из настроек Windows: светлая тема — светлое окно,
тёмная — тёмное. Значок в трее рисуется кодом на условном холсте 100×100 и
масштабируется под запрошенный размер, поэтому остаётся чётким и при 100 %, и при
150 % масштабе. Пока идёт перевод, он серый, при ошибке — красный.

Скрипты в `tools/` нужны только для пересборки картинок, на сборку программы они
не влияют:

```bash
pip install Pillow
python3 tools/generate_icon.py
python3 tools/generate_preview.py
```
